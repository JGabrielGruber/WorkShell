# Arquitetura de Renderização Neural Direta (SIMD / WebGPU)

Status: Aprovado em Pré-Execução • Target: Chrome/Firefox Desktop 120+

1. Contexto & Objetivo

O módulo NeuralRenderBridge faz a ponte de dados entre tensores de inferência matemática e texturas RGBA em ponto flutuante diretamente no pipeline de rasterização.

pipeline_config.ts TypeScript / WGSL 
export const neuralPipelineConfig = {
  devicePreference: 'high-performance',
  tensorPrecision: 'float16',
  bindingGroupLayout: {
    entries: [
      { binding: 0, visibility: GPUShaderStage.COMPUTE, buffer: { type: 'read-only-storage' } },
      { binding: 1, visibility: GPUShaderStage.COMPUTE, storageTexture: { format: 'rgba16float' } }
    ]
  }
};
