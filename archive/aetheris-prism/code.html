01. Kernel de Intersecção de Raios Prismáticos

A propagação da luz em cada vértice dos cubos geométricos calcula a dupla refração interna de Fresnel com índice refrativo fixado em η = 1.520 (Vidro Crown). O pipeline neural desacopla os bounces secundários utilizando vetores de aproximação tensorizados:

prism_dispersion_kernel.wgsl WGSL Compute • 64 threads/group 
@compute @workgroup_size(8, 8, 1)
fn cs_refraction_pass(@builtin(global_invocation_id) id: vec3<u32>) {
    let ray_origin = buffer_rays.origins[id.x];
    let normal     = sample_normal_map(id.xy);
    // Cálculo de dispersão com separação espectral RGB
    let ior_rgb    = vec3<f32>(1.514, 1.520, 1.528);
    let refract_r  = refract(ray_origin.dir, normal, 1.0 / ior_rgb.r);
    let refract_b  = refract(ray_origin.dir, normal, 1.0 / ior_rgb.b);
    
    output_tensor[id.xy] = neural_accumulate(refract_r, refract_b, 0.42);
}
